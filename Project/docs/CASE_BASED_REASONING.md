# Расуђивање по случајевима (Case-Based Reasoning)

## Преглед

Овај модул имплементира **расуђивање по случајевима** (CBR) за кривична дјела против
платног промета (Глава 23 КЗ ЦГ) коришћењем **jCOLIBRI** оквира.

Систем анализира нови случај и проналази **5 најсличнијих** претходних судских одлука
из базе од **127 случајева** екстрахованих из Akomanotoso XML докумената.

## Правна област

- **Члан 258** – Фалсификовање новца (57 случајева)
- **Члан 260** – Злоупотреба платних картица (70 случајева)

## Кључне чињенице (атрибути) – 19 кључних чињеница

| # | Атрибут | Тип | Функција сличности | Образложење |
|---|---------|-----|---------------------|-------------|
| 1 | `tipKrivicnogDjela` | String | TabularSimilarity | Фалсификовање новца и злоупотреба картица су различита дјела исте главе КЗ; сличност 0.3 |
| 2 | `clanKZ` | String | TabularSimilarity | Ставови истог члана су сличнији (0.7) него чланови различитих дјела (0.2) |
| 3 | `iznos` | Double (EUR) | IntervalSimilarity(15000) | Максимални износ једне трансакције; интервал 15000€ (праг за квалификовани облик) |
| 4 | `ranijeOsudjivan` | String | TabularSimilarity | Рецидивизам утиче на одмјеравање казне; да/не = 0.0, непознат = 0.3 |
| 5 | `uslovnaOsuda` | String | Equal | Бинарно - да ли је изречена условна осуда |
| 6 | `vrstaPresude` | String | TabularSimilarity | Осуђујућа/условна = 0.6 (обје значе кривицу), ослобађајућа vs остале = 0.1 |
| 7 | `zaposlenost` | String | TabularSimilarity | Имовно стање утиче на казну; незапослен/студент = 0.6, запослен/незапослен = 0.3 |
| 8 | `bracniStatus` | String | TabularSimilarity | Породичне прилике утичу на одмјеравање казне |
| 9 | `kaznaUMjesecima` | Double | IntervalSimilarity(60) | Затворска казна у мјесецима; интервал 60 мј = 5 година |
| 10 | `novcanaKazna` | Double (EUR) | IntervalSimilarity(5000) | Новчана казна; интервал до 5000 EUR |
| 11 | `obrazovanje` | String | TabularSimilarity | Ниво образовања (SSS/VSS/основна/писмен); утиче на околности |
| 12 | `ukupanIznos` | Double (EUR) | IntervalSimilarity(50000) | Укупан збир свих износа — укупна штета |
| 13 | `brojTransakcija` | Int | IntervalSimilarity(30) | Број појединачних трансакција — упорност у вршењу дјела |
| 14 | `brojOkrivljenih` | Int | ThresholdSimilarity(2) | Број окривљених — организовано извршење као отежавајућа околност |
| 15 | `brojSvjedoka` | Int | IntervalSimilarity(10) | Број свједока — снага доказног материјала |
| 16 | `brojDokaza` | Int | IntervalSimilarity(15) | Број доказних средстава — обим истраге |
| 17 | `priznanje` | String | Equal | Да ли је окривљени признао кривицу — олакшавајућа околност |
| 18 | `pokusaj` | String | Equal | Да ли је дјело остало у покушају — блажа казна |
| 19 | `saizvrsilastvo` | String | Equal | Да ли постоји саизвршилаштво/саучесништво — отежавајућа околност |

**Глобална функција сличности**: Просјек (Average) свих локалних сличности.

## Структура пројекта

```
presude-cbr/
├── pom.xml                              # Maven конфигурација (jCOLIBRI 3.2)
├── src/main/java/
│   ├── cbr/CbrApplication.java          # Главна CBR апликација
│   ├── connector/CsvConnector.java      # Конектор за читање CSV базе
│   ├── model/CaseDescription.java       # Модел случаја (19 атрибута)
│   └── similarity/
│       ├── TabularSimilarity.java       # Табеларна сличност за категоричке атрибуте
│       ├── IntervalSimilarity.java      # Интервална сличност за нумеричке атрибуте
│       └── ThresholdSimilarity.java     # Прагова сличност (помоћна)
└── src/main/resources/
    └── presude.csv                      # База случајева (127 записа)
```

## Образложење функција сличности

### 1. Тип кривичног дјела (`TabularSimilarity`)
- falsifikovanje novca ↔ zloupotreba platnih kartica = **0.3**
- Образложење: различити елементи бића дјела, али иста заштићена вриједност (платни промет)

### 2. Члан КЗ (`TabularSimilarity`)
- čl. 258 ↔ čl. 258 st. 2 = **0.7** (исти члан, различити ставови)
- čl. 258 ↔ čl. 258 st. 4 = **0.5** (привилеговани облик)
- čl. 260 st. 1 ↔ čl. 260 st. 2 = **0.7** (исти члан)
- čl. 258 ↔ čl. 260 = **0.2** (различита кривична дјела)
- Образложење: ставови истог члана имају сличне санкције и елементе бића

### 3. Износ (`IntervalSimilarity`, interval=15000)
- Образложење: Праг од 15.000€ је квалификаторна граница (чл. 258 ст. 3)
- sim(100, 200) ≈ 0.99 | sim(100, 7600) ≈ 0.50

### 4. Рецидивизам (`TabularSimilarity`)
- da ↔ ne = **0.0** (рецидивист добија значајно строжију казну)
- nepoznat ↔ da/ne = **0.3**
- Образложење: ранија осуђиваност је отежавајућа околност

### 5. Условна осуда (`Equal`)
- Образложење: бинарно поље, релевантно само при тачном подударању

### 6. Врста пресуде (`TabularSimilarity`)
- osudjujuca ↔ uslovna = **0.6** (обје утврђују кривицу)
- osudjujuca ↔ oslobadjajuca = **0.1** (супротни исходи)
- Образложење: условна и осуђујућа обје подразумијевају утврђену кривицу

### 7. Запосленост (`TabularSimilarity`)
- zaposlen ↔ nezaposlen = **0.3** | nezaposlen ↔ student = **0.6**
- Образложење: имовно стање утиче на одмјеравање новчане казне

### 8. Брачни статус (`TabularSimilarity`)
- ozenjen ↔ neozenjen = **0.5** | neozenjen ↔ razveden = **0.6**
- Образложење: породичне прилике се разматрају при одмјеравању казне

### 9. Затворска казна (`IntervalSimilarity`, interval=60)
- Образложење: максимално 5 година за чл. 260; sim(6mj, 12mj) ≈ 0.90

### 10. Новчана казна (`IntervalSimilarity`, interval=5000)
- Образложење: покрива уобичајени распон; sim(100, 600) ≈ 0.90

### 11. Образовање (`TabularSimilarity`)
- SSS ↔ VSS = **0.4** | SSS ↔ pismen = **0.6** | osnovna ↔ pismen = **0.7**
- Образложење: ниво образовања утиче на околности случаја и разумијевање последица

### 12. Укупан износ (`IntervalSimilarity`, interval=50000)
- Образложење: укупна штета (збир свих трансакција) — интервал 50.000€ покрива распон картичних превара

### 13. Број трансакција (`IntervalSimilarity`, interval=30)
- Образложење: упорност у понављању кривичног дјела — више трансакција = тежа квалификација

### 14. Број окривљених (`ThresholdSimilarity`, праг=2)
- Образложење: организовано извршење (2+ лица) је отежавајућа околност; sim=1 ако разлика <2

### 15. Број свједока (`IntervalSimilarity`, interval=10)
- Образложење: количина свједока указује на снагу доказног материјала

### 16. Број доказа (`IntervalSimilarity`, interval=15)
- Образложење: обим доказног материјала утиче на поузданост пресуде

### 17. Признање кривице (`Equal`)
- Образложење: признање је значајна **олакшавајућа околност** у одмјеравању казне

### 18. Покушај (`Equal`)
- Образложење: покушај кривичног дјела (чл. 20 КЗ ЦГ) се **блаже кажњава** од довршеног дјела

### 19. Саизвршилаштво (`Equal`)
- Образложење: заједничко извршење по претходном договору (чл. 23 КЗ ЦГ) је **отежавајућа околност**

## Олакшавајуће и отежавајуће околности

CBR систем моделује олакшавајуће/отежавајуће околности кроз комбинацију атрибута:

| Околност | Атрибут(и) | Тип |
|---|---|---|
| Признање кривице | `priznanje` = "da" | Олакшавајућа |
| Покушај дјела (без довршења) | `pokusaj` = "da" | Олакшавајућа |
| Ранија неосуђиваност | `ranijeOsudjivan` = "ne" | Олакшавајућа |
| Рецидивизам | `ranijeOsudjivan` = "da" | Отежавајућа |
| Саизвршилаштво/организовано | `saizvrsilastvo` = "da" + `brojOkrivljenih` > 1 | Отежавајућа |
| Велика штета | `ukupanIznos` висок | Отежавајућа |
| Упорност (више трансакција) | `brojTransakcija` висок | Отежавајућа |
