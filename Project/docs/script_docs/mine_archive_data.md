# mine_archive_data.py

## Опис

Скрипта за **рударење личних података** окривљених из архивских TXT фајлова (сирових
судских одлука) и ажурирање одговарајућих Akoma Ntoso XML фајлова.

Фокусира се на екстракцију података из параграфа о окривљеном у тексту пресуде:
запосленост, образовање, брачни статус и ранија осуђиваност.

## Локација

```
scripts/mine_archive_data.py
```

## Покретање

```powershell
py scripts/mine_archive_data.py
```

## Улаз и излаз

| Тип | Путања | Опис |
|-----|--------|------|
| Улаз (TXT) | `archive/presude/falsifikovanje novca/*.txt` | Сирове пресуде |
| Улаз (TXT) | `archive/presude/falsifikovanje i zloupotreba.../*.txt` | Сирове пресуде |
| Улаз/Излаз (XML) | `data/cases/akomantoso/*.xml` | XML фајлови — чита и ажурира |

## Подаци који се екстрахују

| Поље | Могуће вриједности | Опис |
|------|--------------------|------|
| `zaposlenost` | zaposlen, nezaposlen, student, penzioner | Радни статус |
| `obrazovanje` | VSS, SSS, osnovna, pismen, nepismen | Ниво образовања |
| `bracniStatus` | ozenjen, neozenjen, razveden, udovac | Брачно стање |
| `ranijeOsudjivan` | da, ne | Ранија осуђиваност |

## Како ради

1. **Мапира** TXT фајлове из архиве на XML фајлове (нпр. `K 1002010.txt` → `K 100_2010.xml`)
2. **Екстрахује параграф** о окривљеном из текста пресуде (секција послије "PRESUDA")
3. **NLP шаблонима** (regex) препознаје вриједности из текста
4. **Ажурира** XML фајлове само ако поље недостаје или има вриједност "nepoznat"

## Кључне функције

| Функција | Опис |
|----------|------|
| `txt_name_to_xml_name()` | Конвертује име TXT фајла у одговарајуће XML име |
| `extract_defendant_paragraph()` | Екстрахује параграф о окривљеном из пресуде |
| `extract_zaposlenost()` | NLP детекција запослености (укључује 20+ занимања) |
| `extract_obrazovanje()` | NLP детекција нивоа образовања |
| `extract_bracni_status()` | NLP детекција брачног статуса |
| `extract_ranije_osudjivan()` | NLP детекција раније осуђиваности |
| `load_xml()` / `set_xml_value()` | Читање и ажурирање XML фајлова |

## Напомена

Ово је **utility скрипта за обогаћивање података**. Покреће се ручно када је потребно
ажурирати XML базу са недостајућим личним подацима. Скрипта мијења XML фајлове in-place,
али само поља са вриједношћу "nepoznat" или празна поља.
