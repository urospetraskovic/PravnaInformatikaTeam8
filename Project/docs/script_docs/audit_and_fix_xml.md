# audit_and_fix_xml.py

## Опис

Скрипта за **аудит квалитета** Akoma Ntoso XML фајлова. Скенира све XML фајлове,
извјештава о пољима која недостају, и упоређује их са одговарајућим TXT фајловима
из архиве да провјери шта је могуће аутоматски попунити.

## Локација

```
scripts/audit_and_fix_xml.py
```

## Покретање

```powershell
py scripts/audit_and_fix_xml.py
```

## Улаз

| Тип | Путања | Опис |
|-----|--------|------|
| XML фајлови | `data/cases/akomantoso/*.xml` | Akoma Ntoso судске одлуке |
| TXT фајлови | `archive/presude/falsifikovanje novca/*.txt` | Сирови текстови пресуда |
| TXT фајлови | `archive/presude/falsifikovanje i zloupotreba.../*.txt` | Сирови текстови пресуда |

## Излаз

Извјештај на стандардном излазу (конзола) са:
- Листом поља која недостају у сваком XML фајлу
- Да ли постоји одговарајући TXT фајл у архиви
- Која поља је могуће аутоматски екстраховати из TXT-а

## Кључне функције

| Функција | Опис |
|----------|------|
| `xml_filename_to_case_id()` | Конвертује XML име у (број, година) |
| `find_txt_file()` | Проналази одговарајући TXT за дати предмет |
| `extract_xml_field()` | Екстрахује вриједност тага из XML-а |
| `extract_from_txt()` | Екстрахује сва поља из TXT фајла (судија, записничар, казна итд.) |

## Напомена

Ово је **дијагностичка utility скрипта**. Покреће се ручно прије `fix_xml_data.py`
да се прво провјери стање података. Генерише само извјештај — не мијења фајлове.
